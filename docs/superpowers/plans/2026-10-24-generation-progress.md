# 创作进度与加载反馈实施计划

**目标：** 在用户截图中的任务按钮上方显示实际处理阶段、已等待时间和加载动画，细化核验错误原因。

**实现：** 保留同步生成接口与业务结果，额外记录四个真实阶段并由页面轮询；不按时间虚构完成百分比。原生 Python、HTML、CSS、JavaScript，无新增依赖。

1. 以隔离资料验证阶段顺序、终态、过期、容量及错误原因。
2. 新增只含阶段信息的内存进度记录。生成接口接受可选的服务端进度引用，既有调用保持兼容；共享 Key 模式继续要求团队登录。
3. 页面显示读取资料、提取事实、创作文案、核验图文四步，阶段切换时填充进度条。单个 CSS 加载环表示等待；减少动态效果时保留静态状态。网络断开、失败、待补充与成功分别显示。
4. 细分声明未逐字出现、事实引用不在本次稿件和响应格式无效，不放宽核验规则或自动重试付费调用。
5. 按仓库验收约定运行相关回归并检查桌面、手机、减少动态效果与失败状态；同步 DESIGN.md、接口说明和真实验证边界。
