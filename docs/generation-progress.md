# 创作进度与核验错误

点击真实创作后，任务按钮上方显示加载环、已等待时间、阶段条与当前操作。四步是读取资料、提取事实、创作文案、核验图文，进度只按真实阶段变化，不预测模型何时返回。同一个阶段停留较久通常表示正在等待外部服务，不代表进度可以按时间自动增加。

完成自动核验才填满进度；缺少资料、核验未通过或请求异常时保留当前进度、停止加载环并显示原因。生成期间禁用任务编辑、新建任务和重复提交，结果返回后恢复。系统设置减少动态效果时不旋转，阶段文字与用时继续显示。

## “声明核验的原文定位或事实引用无效”是什么意思

该提示由独立模型复核返回的声明列表触发，可能是声明被模型改写而未逐字出现在稿件，或引用了不属于本次稿件的事实编号，也可能是响应字段格式不对。旧版将这些原因合在一条提示里，无法仅凭旧截图判断具体一项。

当前版本区分第几条声明无法逐字定位、事实编号引用无效、响应格式无效。核验输入中的事实和引文已限定为稿件实际选用集合，并显式提供允许引用的编号，保留原始 documents 核对条件与冲突。规则仍然拒绝错误核验结果，不猜测、替换编号。

已有结构有效的草稿时，核验异常不再丢失整篇稿件，而是保留为 blocked 草稿，显示待复核项，最终稿复制和导出保持禁用。可在「核验结果」点击「只重新核验」：用服务器保存的原稿和资料调用一次核验模型，不重新提取或写作。不会自动重试；手动操作仍产生模型用量。草稿保留在进程内约一小时，重启后不恢复。

事实范围统一与草稿恢复的验收见 [核验引用修复记录](review-grounding.md)。

## 验证边界

阶段顺序、等待期间查询、成功与失败终态、引用过期和团队权限使用隔离虚构资料验收；浏览器界面验收也使用延时模拟模型，不访问 ima 或百炼、不生成真实营销稿。本轮没有复现截图对应的原始模型响应，不能断言具体是哪条声明出错。真实营销稿仍需单独生成及验收。

2026-10-24：138 项回归通过；真实浏览器在 1440×1000 和 390×844 检查运行、成功、失败、缺少需求、断线提示与减少动态效果。两种尺寸均无横向溢出或脚本错误；失败停在核验阶段、用时停止、控件恢复，减少动态效果时加载环不旋转。界面截图与浏览器记录保留在本次本地验收目录，未作为真实营销产物。

进度信息在服务内存中最多保留 30 分钟；刷新或服务器重启后不恢复原页面任务。网页暂时失去网络时只提示无法查询，不将其误报为任务成功或自动重试生成。
