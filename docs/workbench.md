# 本地内容工作台

## 启动

在仓库根目录安装已有依赖后启动：

```bash
python -m pip install -r requirements.txt
python -m app
```

浏览器打开 http://127.0.0.1:8765 。Windows 可双击 start-workbench.cmd；如端口被占用，使用 python -m app --port 8766 。按 Ctrl+C 停止。

工作台使用 Python 标准库本地服务及静态 HTML/CSS/JavaScript，不需要额外安装前端依赖。它只监听本机回环地址，当前不是公网生产部署。

## 已实现功能

| 功能 | 实际行为 |
|---|---|
| 营销任务表单 | 产品、人群、场景、平台、购买阶段、目标；信息不足时提示补充 |
| 场景预设 | 学生开学、职场移动办公、门店到访，可继续修改 |
| 三平台演示预览 | 不同标题与正文结构，分别安排 3、2、1 张示意配图 |
| 内容策略 | 展示场景切入、内容优先级、平台结构和待确认问题 |
| 依据与核验 | 展示来源状态、配图方案和实际运行的结构检查，保留语义与真实性待复核 |
| 手动修改 | 编辑标题、正文和行动引导；保存后重新执行检查 |
| 复制与导出 | 复制完整 Markdown 或下载文件，保留演示和待核验标记 |
| 最近任务 | 当前浏览器保存最多 10 条演示记录；支持恢复与清空 |
| 本机配置状态 | 显示 Node、官方脚本、凭证与模型配置是否就绪；不返回真实凭证 |
| 真实 ima 连接检查 | 精确查找指定共享库并浏览首屏目录 |
| 真实 ima 条目检索 | 搜索型号或关键词，显示标题和去除 HTML 标签的摘要；空结果时回退目录 |

## 演示与真实检索的边界

演示预览是按规则组织的结构样例，不调用大模型。资料与图片为占位，不能作为真实产品事实、正式发布稿或参赛运行证明。配图是自行绘制的通用电脑构图，不代表具体型号。

真实检索确实调用指定 ima 共享库，但当前只完成条目定位和摘要展示。尚未自动读取产品原文、获取真实图片、逐项核验产品声明或调用模型生成最终稿。即使连接成功，也不会把这些能力标记成已完成。

## 凭证配置

按 ima-setup.md 在本机 .env 中配置。修改 .env 后需重启工作台；代码库只提供空的 .env.example。页面不提供密钥输入或返回接口，真实搜索结果不包含内部知识库 / 媒体 ID 或临时访问请求头。

## 接口

- GET /api/status：本机配置和最近连接状态。
- POST /api/prepare：检查 task，生成补充问题和平台规则。
- POST /api/demo：用 task 组织明确标注的开发演示。
- POST /api/review：对 task / evidence / article 重新检查结构及引用。
- POST /api/probe：检查指定知识库连接。
- POST /api/search：在指定知识库搜索 query，仅返回标题与摘要。

共享数据契约未修改；演示报告与最终 Agent ready 状态分开。应用不将完整结构检查当作语义、来源或图像真实性认证。

## 验证

```bash
python -m unittest discover -s tests -v
```

工作台测试包含实际本地 HTTP 请求，外部 ima 使用模拟客户端；这些测试不替代参赛账号的真实连接和产品检索验证。

本次已通过 44 项自动测试，并在 Edge 浏览器完成桌面及手机宽度的流程验证，包括三平台预览、编辑复核、复制、Markdown 下载、历史恢复与真实 ima 搜索。本机共享库连接和产品条目搜索已实际成功；尚未核验产品原文和实际图片。
