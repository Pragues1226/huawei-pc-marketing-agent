# 本地内容工作台

## 启动

在仓库根目录安装已有依赖后启动：

```bash
python -m pip install -r requirements.txt
python -m app
```

浏览器打开 http://127.0.0.1:8765 。Windows 可双击 start-workbench.cmd；如端口被占用，使用 python -m app --port 8766 。按 Ctrl+C 停止。

工作台使用 Python 标准库本地服务及静态 HTML/CSS/JavaScript，不需要额外安装前端依赖。它只监听本机回环地址，当前不是公网生产部署。

## 已实现功能

| 功能 | 实际行为 |
|---|---|
| 营销任务表单 | 产品、人群、场景、平台、购买阶段、目标；信息不足时提示补充 |
| 场景预设 | 学生开学、职场移动办公、门店到访，可继续修改 |
| 三平台演示预览 | 不同标题与正文结构，分别安排 3、2、1 张示意配图 |
| 三平台对照 | 固定当前任务和所选内容方向生成三版草稿；采用某一版时保留方向与创意形式，导出摘要记录固定方向；手机端可切换查看失败平台，支持从单卡重试或批量重试，失败恢复保留已生成稿 |
| 内容策略 | 展示场景切入、内容优先级、平台结构和待确认问题 |
| 内容切入方向 | 规则演示可固定任务与平台，在需求清单、一日流程和真实任务体验三种叙事方向间切换，并重跑整篇示例；不调用模型，不加入产品事实 |
| 互动 IP 小游戏 | 按受众和场景生成路线、任务题与突发事件；每类场景含两种事件，重玩会必定切换到同场景的另一事件，同时轮换选项顺序，首题会预告新事件（例如校园“最终稿分身术 / 群聊艾特风暴”、会议“转接头迷雾 / 会议室瞬移事件”、创作“格式幽灵 / 素材分身现场”、到店“样机体验迷雾 / 十分钟试玩冲刺”、通用“兼容性问号怪 / 评论区回音室”）。到店路线让玩家带真实任务按准确型号体验，满分称号按本局突发事件解锁，例如“最终稿分身术”对应“版本分身捕手”、“会议室瞬移事件”对应“五分钟救场队长”，满分称号会保存在本机事件图鉴，跨任务累计解锁；选场景前可展开十项图鉴和总进度。原创向导“小P”带玩家完成三题选择闯关，选项含轻梗反馈、徽章和连击计分；桌面支持 1–3 键作答，逐题进度可见，答对反馈轻微动效并遵循减少动态效果设置，答错不扣徽章。通关后可下载 PNG 战绩卡；工作台在支持系统分享的浏览器中直接打开分享面板，其他浏览器复制战报，均标出本局遭遇事件并附邀请语；战绩卡不含身份或选择明细。真实模式可将规则生成的小游戏附在已核验图文之后，游戏本身不加入产品功能、价格或权益主张。演示战绩保存在本机最近任务，可恢复、重玩、复制记录，导出列有全部事件分支的玩法脚本或可脱离工作台离线试玩的单文件 HTML |
| 依据与核验 | 真实模式展示提取事实、原文引文、来源与图片；结构规则后由独立模型核验声明和实际图片输入。声明—事实关联总览显示有依据关联与未关联项，可跳到事实卡；模型通过不保证结论无误，仍需人工复核。图片核验卡可跳到对应配图、图注与来源；人工结论与备注单独记录 |
| 核验后的修改 | 有待处理项时可从核验页返回草稿；演示模式打开编辑面板，真实模式定位到修改意见输入并重新核验 |
| 真实生成与重写 | 配置 ima 与模型服务后，从选中原文提取事实、生成图文、独立复核；按修改意见重写后再次复核。信息不足或无草稿返回时停止交付，页面定位到任务表单显示具体追问或核验原因 |
| 手动修改 | 编辑标题、正文和行动引导；保存后重新执行检查 |
| 任务变更保护 | 生成后修改型号、人群、场景、购买阶段、内容目标、平台、工作模式或创意形式时，提示右侧仍为旧结果并暂停复制、导出和编辑；真实检索时更改型号会清除旧检索结果与已选资料 |
| 复制与导出 | 复制 Markdown 或导出离线 HTML；演示稿与真实稿均记录任务契约、购买阶段和策略方向；真实结果附逐条声明到事实、条件、原文摘录和来源的映射，演示结果保留待核验标记 |
| 最近任务 | 当前浏览器保存最多 10 条演示记录；小游戏进度可恢复，未完成时入口显示“继续小P挑战”，完成后显示“查看挑战战绩”；支持清空 |
| 任务草稿 | 表单内容、平台、工作模式和创意形式自动保存在当前浏览器；刷新后恢复。凭证和知识库资料不写入草稿 |
| 演示版本回放 | 在策略页选择一条历史演示，对照任务输入、内容方向、策略、开场、正文结构和草稿字段，并可打开历史版本 |
| 本机配置状态 | 显示 Node、官方脚本、凭证与模型配置是否就绪；不返回真实凭证 |
| 真实 ima 连接检查 | 精确查找指定共享库并浏览首屏目录 |
| 真实 ima 条目检索 | 搜索型号或关键词，显示标题和去除 HTML 标签的摘要；空结果时回退目录 |
| 真实目录与资料读取 | 文件夹导航、分类、分页；打开实际原文和图片并保留来源 |
| 资料篮与调用包 | 选择最多 8 份资料，返回原文、真实图片、本机引用、来源与异常说明 |

## 演示与真实检索的边界

策略拆解中的“边界压力测试”提供四个确定性规则演练：缺少具体型号、型号描述含糊、无依据的宣传与补贴、图片与型号不匹配。可以单项运行或依次运行全部用例，并导出 Markdown 结果。报告仅含已运行用例的实际规则返回；不调用 ima 或模型，不代表真实产品事实、模型语义或法律合规结论。

演示预览是按规则组织的结构样例，不调用大模型。资料与图片为占位，不能作为真实产品事实、正式发布稿或参赛运行证明。配图是自行绘制的通用电脑构图，不代表具体型号。

真实检索调用指定 ima 共享库，支持条目定位、目录导航、产品原文和真实图片读取，以及将选中资料组成原始上下文。资料篮与调用包仅用于核对和准备上下文，本身不代表已生成或核验营销文案。使用说明与格式限制见 [真实检索与原文调用](knowledge-retrieval.md)。

真实生成链路已在代码中实现：从指定资料提取事实和可定位引文，按事实生成草稿，再以独立核验步骤检查声明、适用条件、平台和真实图片输入；未达到全部通过条件时不标记为 ready。该自动核验仍可能遗漏语义问题。本机最近一次 `/api/status` 检查显示 ima 与模型凭证均未配置，因此此环境尚不能完成真实端到端运行。

## 凭证配置

按 ima-setup.md 在本机 .env 中配置。修改 .env 后需重启工作台；代码库只提供空的 .env.example。页面不提供密钥输入或返回接口，真实搜索结果不包含内部知识库 / 媒体 ID 或临时访问请求头。

## 接口

- GET /api/status：本机配置和最近连接状态。
- POST /api/prepare：检查 task，生成补充问题和平台规则。
- POST /api/demo：用 task 组织明确标注的开发演示；可选 angle_id 为 task_list、daily_flow 或 experience_task，以生成对应规则切入方向。
- POST /api/review：对 task / evidence / article 重新检查结构及引用。
- POST /api/probe：检查指定知识库连接。
- POST /api/search：在指定知识库搜索 query，仅返回标题与摘要。
- POST /api/browse：目录导航与分页。
- POST /api/read：读取检索结果对应的原文或图片。
- POST /api/retrieve：读取选中的原文与图片，返回带来源的上下文。
- POST /api/generate：检索已选资料并运行真实生成与核验流程；需要本机 ima 与模型配置。
- POST /api/revise：按修改意见或编辑后的正文重新生成核验结果。
- GET /api/asset/本机引用：在本机预览已读取的真实图片。

共享数据契约未修改；演示报告与最终 Agent ready 状态分开。应用不将完整结构检查当作语义、来源或图像真实性认证。

## 验证

```bash
python -m unittest discover -s tests -v
```

工作台测试包含实际本地 HTTP 请求，外部 ima 使用模拟客户端；这些测试不替代参赛账号的真实连接和产品检索验证。

本轮已在手机视口用本地构造的核验结果检查“查看事实依据”跳转；这验证的是界面行为，不是真实生成。不要将历史自动测试或真实资料读取记录当作当前模型凭证已就绪的证明。复赛提交前需完成真实端到端运行，并保存三组可复核结果。

最近任务在本机浏览器保留最近 10 条开发演示；同一任务手动修改并保存后，会记录前一版标题、正文和行动引导，最多保留最近 5 次修改。历史页可选择任一次改稿，查看修改前后差异；旧格式历史记录仍可照常打开。历史数据只在当前浏览器，不会上传。

策略页包含需求契约卡；若开发演示因缺少信息或型号不明确而无法生成，表单提示也会展示该卡。卡片按当前任务表单展示型号、人群、场景、购买阶段、内容目标和发布平台，标明信息来源、必填完整度及可选项。它只反映已填字段，不抽取或保存原始自然语言需求；缺项可直接返回相应表单补全。
