# 电影封面与景观工作台

本说明对应用户已批准的当前原生 HTML/CSS/JavaScript 界面。入口是 Experience 表达，进入后的内容工作面板以 Operate 为主。设计令牌和完整交互规范见 [DESIGN.md](../DESIGN.md)，官网资料与本地 v7 的配置见 [官网与本地创作指导](official-guidance.md)。

## 启动与进入

Windows 可双击项目根目录的 `start-workbench.cmd`。也可在项目根目录运行：

```powershell
python -m app
```

默认浏览器地址为 `http://127.0.0.1:8765`。需要另一预览端口时运行 `python -m app --port 8766`，再访问该端口；两者使用同一套代码。

每次打开或刷新均先看到“越过想象”封面。点击“开始创作”播放约 2.4 秒的桥洞推进；右上角“直接进入工作台”可跳过。旧地址中的 `#studio` 不会自动跳过。工作台右上角“返回封面”可收起当前面板、重置镜头并重新观看，不刷新整页。

系统开启“减少动态效果”时仍需点击入口，但直接显示工作台，不播放推进或指针视差；景观、卡片退后、面板和产品图的本轮过渡也停止。

## 完整景观与功能卡片

工作台保留清晰的 Mostar 天空、远城和河流。推进镜头停在进度 0.58，行程 68% 后以 1100ms 揭示工作台，并交叉淡入一组完整景观层。最终暖白遮罩为 **7%**，不是旧版的 86%。照片层固定、不接收鼠标事件，功能面板使用不透明纸面。

顶部七张功能卡片依次为：创作任务、内容策略、资料与配图、图文预览、核验与导出、最近任务、知识库连接。可以在卡片区滚动鼠标、触控横滑或点击左右按钮寻找功能；键盘左右键、Home、End 可在卡片间移动。卡片只显示中文功能名与说明，不生成英文眉题。

点击功能后，顶部卡片以 620ms 退后缩小、淡化，当前工作面板在**屏幕正中心**展开，内容在面板内部滚动。桌面导航缩为 .83、透明度 .32，窄屏缩为 .8、透明度 .28。点击右上角关闭按钮或按 Esc 收起面板，卡片恢复并将焦点归还原卡片。面板是可切换的工作区，没有模态焦点陷阱，页头和卡片仍可操作。

旧侧栏、旧顶部条、流程条及输入/结果双栏已在这套景观界面隐藏；不要按旧侧栏宽度或旧双栏布局验收当前界面。

## 官网产品主视觉与原文

在“创作任务”选择“真实图文创作”，资料来源选“华为官网”，填写完整型号、人群、场景与平台。点击“读取官网介绍与图片”即可查看资料，读取本身不需要模型。

产品区显示服务端确认的完整型号、官网原页、读取时间和官网介绍原文；展开“官网原文”可核对脚注与限制条件。原文仅整理 HTML 空白，不因版面需要改写或截掉条件。官网 KV 主视觉优先作为默认图；主图宽度铺满容器，使用 contain 完整展示，图高为 clamp(210px, 34vh, 360px)，成功载入后以 760ms 自然入场。点击缩略图可切换，选中状态清晰可见。单图加载失败时提示选择其他图或重新读取；选择其他缩略图可恢复显示。

型号范围固定为十个明确产品，并非全部华为 PC：

1. HUAWEI MateBook 14（鸿蒙版）
2. HUAWEI MateBook Pro（鸿蒙版）
3. HUAWEI MateBook Pro S
4. HUAWEI MateBook Fold 非凡大师
5. HUAWEI MateBook 14 酷睿 Ultra
6. HUAWEI MateBook D 14 2024
7. HUAWEI MateBook D 16 2024
8. HUAWEI MateBook D 16 SE 版 2024
9. HUAWEI MateBook GT 14
10. HUAWEI MateBook X Pro 酷睿 Ultra 微绒典藏版

必须区分系统、销售版本与年份，不明确的型号不会自动猜测。官网图片由同源本地接口返回服务端签发的内存引用，经过真实图片签名检查和内容去重，缓存约一小时；重启、过期或淘汰后需重新读取，不能把这些引用当作永久素材地址。前端按本次型号、平台、人群与场景最多复用预备资料 45 分钟。

本地 v7 直接只读使用已配置的指导目录，按治理/引用规则、发布平台、型号角色和客户场景选取文档；学生任务优先学生沟通表达。界面只展示实际读取的标题。它用于结构、语气和场景，不替代本次官网或 ima 的产品事实，也不冒充 ima 实时检索。

## 设计来源与外部依赖

本轮使用五项指定设计技能：taste 保持景观方向与浏览器核对；impeccable 整理令牌、状态和规范；shadcn 仅采用 Carousel/Tabs 和可访问组件的组织原则，未安装 shadcn 组件、未迁移到 React；UI UX Pro Max 核对可读性、焦点、触控和响应布局；Design MD Collection 借鉴其 Apple 参考的产品摄影份量与留白，保留 Mostar 方向。该参考集合不是官方品牌规范。

Mostar 六张场景照片及 Ogg Medium 英文字体直接从 `motionsites.org/assets/prompt-media/` 加载，需要网络，没有随项目打包为离线资源。新工作台景观复用天空、光晕与远城图片。至少两张原封面图片加载报错时显示“场景图片加载受限，可直接进入工作台”；仍可点击直接进入。没有图片超时替换或完整离线场景。

中文标题与引文优先使用本机“思源宋体 VF”，缺失时降级到 Source Han Serif SC VF、Songti SC 或系统衬线字体，字形可能不同；项目未分发或下载该中文字体。官网原文与图片另依赖华为消费者官网可访问，本地 v7 依赖指定目录可读。
