# Windows 启动器

1. 双击项目根目录的 `启动工作台.cmd`，或桌面的“华为PC工作台-新版UI”快捷方式。
2. 等待浏览器自动打开“越过想象”封面，再点击“开始创作”。
3. 在横向功能卡片中选择“创作任务”等入口，打开居中内容工作面板。

启动器始终从自身所在的项目目录运行，窗口会显示项目路径及实际 URL。默认尝试 8765；端口占用时尝试后续 9 个端口，不会终止其他服务。请使用本次启动窗口显示的地址。

需要 Python 3.10+；优先使用项目 `.venv`，其次检查系统 `python` 和 `py -3`。缺少 Python 时会显示安装提示；缺少依赖时在项目 `.venv` 中安装 `requirements.txt`，需要网络。保持启动窗口打开；按 Ctrl+C 或关闭窗口可停止本机服务。

直接打开 `app/static/index.html` 会跳到 `START.html`，说明正确启动步骤。启动器保留现有封面、功能卡片、官网产品来源、ima 与本地指导逻辑；它不会复制其他项目的凭证。未配置模型/ima 仍可显示 UI 及规则演示，真实创作需要相应服务配置。

当前风景图和部分字体来自现有页面的 motionsites.org 外部资源，需要网络可达；这不是启动器下载的模型或产品资料。浏览器历史记录按本地地址及端口分别保存。
