# Windows 启动器

1. 双击项目根目录的 `启动工作台.cmd`，或桌面的“华为PC工作台-新版UI”快捷方式。
2. 等待浏览器自动打开“越过想象”封面，再点击“开始创作”。
3. 在横向功能卡片中选择“创作任务”等入口，打开居中内容工作面板。

启动器始终从自身所在的项目目录运行，窗口会显示项目路径及实际 URL。默认尝试 8765；端口占用时尝试后续 9 个端口，不会终止其他服务。请使用本次启动窗口显示的地址。

启动器优先使用项目 `.venv`。当它缺失或无效时，使用随附 `.runtime/python/` 中的 Python 3.10+ 重建；源码副本没有内置运行时时，才检查系统 `python` 和 `py -3`。依赖始终安装在项目 `.venv`，优先从 `.runtime/wheels/` 离线安装；没有离线包时才需要联网。依赖清单通过启动文件所在目录的绝对路径读取。两个 CMD 入口使用 ASCII 和 Windows CRLF，避免中文代码页导致命令被截断。保持启动窗口打开；按 Ctrl+C 或关闭窗口可停止本机服务。

直接打开 `app/static/index.html` 会跳到 `START.html`，说明正确启动步骤。启动器保留现有封面、功能卡片、官网产品来源、ima 与本地指导逻辑；它不会复制其他项目的凭证。未配置模型/ima 仍可显示 UI 及规则演示，真实创作需要相应服务配置。

当前风景图和部分字体来自现有页面的 motionsites.org 外部资源，需要网络可达；这不是启动器下载的模型或产品资料。浏览器历史记录按本地地址及端口分别保存。

## v2.0 本地运行环境（2026-10-24）

本机副本已在项目目录内准备 CPython 3.13.12（Windows x64）、项目虚拟环境和 7 个依赖离线包。运行时位于 .runtime/python，离线包位于 .runtime/wheels，应用使用 .venv。Python 的原始许可证保留在运行时目录中。运行与离线安装不依赖其他项目目录或系统 PATH，也没有修改系统 Python。移动或备份本地运行包时，保留整个 .runtime 目录；.venv 无法使用时启动器会利用本地 Python 重新准备。运行时为本机交付文件，已加入 Git 忽略；仅从 GitHub 下载源码时不包含这些二进制文件。
