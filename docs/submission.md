# 提交检查清单

## 初赛必备

- [ ] GitHub 源码、README、安装方法、启动方法与依赖说明完整。
- [ ] 魔搭页面存在，信息与 GitHub 和说明书一致。
- [ ] 作品说明书写明功能，并至少包含一组可辨认的真实运行结果。
- [ ] 链接在评审期内可访问，无需额外授权；私有仓库需在提交前处理访问范围。
- [ ] 能清楚说明自研 Agent 在场景理解、平台策略与核验中的作用。

## 复赛补充

- [ ] 不少于三组优秀运行结果，覆盖至少两类场景、两个平台，并标注资料与图片来源。
- [ ] 真实录屏展示输入、ima 调用、图文生成及核验，并补换场景或换平台结果。
- [ ] 视频、说明书和运行应用保持一致，记录已知限制。

## 发布前

- [ ] 检查整个 Git 历史及文档中无 API Key、Client ID、登录信息和其他机密。
- [ ] 未上传赛题原件、知识库压缩包、共享资料原文和未经授权图片。
- [ ] 仓库没有把骨架、开发样例或计划功能标为已实现。
- [ ] 说明书删除全部未填写项，只保留真实功能与真实结果。
- [ ] 更换浏览器会话检查评审链接；实际启动一次应用。
