# 团队共用 QwenImage 接入

## 目标与边界

用户在项目网站中创建管理员、配置一份 QwenImage Key，团队共用后端生图服务，不要求成员编辑本机 .env。沿用原生 HTML/CSS/JavaScript 与 Python 服务，不替换现有资料、文案和核验流程。

## 实施顺序

1. 后端：管理员与成员登录、受保护的服务器配置、QwenImage Images 协议调用、图片校验与同源预览。配置不回传密钥；首次创建管理员仅限直接本机访问，部署后需使用平台设置的初始化码。配置保存在被忽略的 private 目录，云部署需要持久卷。
2. 页面：沿用 DESIGN.md 的现有表单与颜色，在连接设置中添加登录、管理和生图区，并从资料与配图提供快捷入口。提供保存、清除、加载、失败和下载状态。不自动消费生图额度。
3. 验证：配置权限与持久化、协议模拟、原有工作台回归、桌面与窄屏浏览器检查。没有新 Key 时不声称实际模型已验证。记录使用方法与部署限制。

## 数据约束

- API Key 只由后端保存和使用，不进入浏览器存储、源码、公开响应和日志。
- 管理员密码与团队访问码分别保存盐化哈希，登录使用 HttpOnly 会话。
- 图片生成单独展示为 AI 场景示意，不进入事实证据、真实产品图或 ready 核验。
- 生图地址仅允许官方百炼 HTTPS 域名；图片使用服务端签发的同源引用。
- 云端必须设置固定公开来源与持久化目录；当前本机运行不代表已部署公网。
