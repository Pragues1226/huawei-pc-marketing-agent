# 网站中的文案与图片核验模型

QwenImage 负责生成场景图。文案、资料事实提取和产品图片核验通过另一个支持看图的模型执行，两者可以使用同一份百炼 API Key。

## 管理员设置

1. 启动项目，在网页点击「连接设置」，使用已有管理员密码登录。
2. 已保存团队 Key 时无需再填写。在「文案与图片核验」选择账号可用的视觉模型，点击「保存文案模型」。当前本机选用 `qwen3-vl-plus`。
3. 点击「验证看图与 JSON」检查实际调用。验证使用服务端生成的纯色色块，不读取知识库；会产生模型用量，不自动重试。
4. 成功后显示「看图与 JSON 已验证」。回到任务页重新发起生成；若事实不足或图片核验未通过，原有流程仍会停止并显示原因。

团队成员沿用原有访问码登录，可生成和修改文案，不能更改模型或验证配置。服务器重启后需重新登录，保存的模型设置与 Key 保留。

## 配置与数据边界

- 网站配置即时应用于 ima 与官网两种生成流程。原有业务提示词、资料选择与核验规则保留。
- 模型选择与验证状态保存在 `private/image-studio.json` 的 `text_model` 字段；实际 Key 仍只保存一份。浏览器不会回填 Key，也不需要编辑 `.env`。
- 文案请求复用生图配置的 Key、地域和 Base URL，请确认此地址同时支持 Chat Completions。更换 Key 或地址后需重新验证；清除 Key 会停用两种调用。
- 共享文案模式启用 JSON 输出并关闭思考模式。未选择网站共享文案模式时，原有 `LLM_API_KEY`、`LLM_BASE_URL`、`LLM_MODEL` 环境配置继续有效。
- 保存模型不触发模型调用。点击任务生成时，所选资料和图片按现有流程发送至模型，仍需使用获得授权的内容。
- 验证标记表示最近一次色块识别及 JSON 测试成功，不保证后续额度、服务可用性或营销稿质量。
