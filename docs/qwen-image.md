# 在网站中配置团队共用的 QwenImage

## 管理员操作

1. 启动本项目，进入封面后点击右上角「连接设置」，或选择「连接与生图」功能卡片。
2. 首次使用时创建管理员密码（至少 10 位）与独立的团队访问码（至少 8 位）。管理员密码用于管理，团队访问码用于生图及已启用的共享文案模型调用。
3. 在「场景生图与团队 Key」粘贴百炼 API Key，选择已开通的模型，保存配置。北京地域默认 Base URL 为 `https://dashscope.aliyuncs.com/compatible-mode/v1`，也支持控制台给出的业务空间专属地址。其他地域需要使用该地域对应的 Key 和地址。
4. 保存成功不代表已验证模型，也不会消费生图额度。填写画面描述、选择比例，再点击「生成场景图」才发起一次真实请求。页面明确显示生成中、成功或失败。
5. 在「文案与图片核验」单独选择支持看图的文案模型，再保存。该模型复用团队 Key，详细操作见 [文案模型配置](shared-text-model.md)。
6. 下载检查过的图片。需要停止新请求时，管理员可「清除 Key」；生图与使用该 Key 的文案调用都将停用，已提交的请求可能仍在执行。

现有 Key 不回显；更换 Key 时粘贴新值，留空保存保留原 Key。退出后可选择管理员或团队成员身份重新登录。

## 团队成员操作

连接设置 → 团队成员 → 输入管理员分发的团队访问码。成员使用同一份服务器配置，不需要获得 API Key，不能修改或清除配置。「资料与配图」的空状态也提供场景生图入口。

## 图片与业务边界

- 当前支持的模型包括 `qwen-image-3.0-pro`、`qwen-image-3.0`、`qwen-image-2.1-pro`、`qwen-image-2.1-turbo`，具体可用性取决于账号地域与权限。旧版 `qwen-image` / `qwen-image-plus` 需要其他协议，不在当前入口支持范围。
- 默认百炼通用域名使用 DashScope 原生多模态同步接口；业务空间专属域名保留 OpenAI Images 协议。程序按官方域名选择协议，不在失败后自动切换重试。界面仍填写原有 Base URL，不需要改动已保存的 Key。
- 每次生成 1 张，支持 1:1、3:4、4:3；服务同一时间只处理一张，不自动重试付费调用。遇到超时先核对百炼调用记录，再决定是否重试。
- 服务端验证图片签名与尺寸范围，下载官方结果至内存，再提供同源预览。最多缓存 12 张，约 1 小时后失效；重启后清除，请及时下载。
- 场景图明确标注「AI 场景示意」，不自动合并进图文稿、不冒充 ima 来源、真实产品图片或核验通过项。人工检查产品、文字与画面后再使用。
- 「使用当前任务场景」只组织场景提示词，不读取或上传 ima 原文、产品图片、内部指导文件。当前入口未实现图生图、产品抠图合成或团队历史图库。
- 生图模型与文案/图片核验模型分别选择，可复用同一百炼 Key；只保存 QwenImage 配置不会自动选择文案模型。ima 凭证仍独立。

## 保存方式与上线

本项目不要求把 QwenImage Key 写到各成员电脑的 `.env`。管理员在网页填写后，由运行项目的 Python 后端保存到 `private/image-studio.json`。这是服务器的敏感配置文件，不是公开网页资源；没有宣称已对文件加密。管理员密码及团队访问码存储为 PBKDF2 盐化哈希，Key 仅用于后端请求。不要复制或公开 private 目录。

- `.gitignore` 与 `.dockerignore` 排除 private。Linux 新配置目录权限为 700，文件为 600；Windows 继承运行账户的目录权限。服务器和备份的访问权限仍需由部署管理员管理。
- 默认状态目录在项目根目录的 private；云部署应设置 `WORKBENCH_STATE_DIR` 指向持久卷，临时容器文件系统不能保证重启或重建后保留。
- 首次创建管理员只允许直接访问本机服务。随项目提供的反向代理会标注外部请求；云部署需在平台机密设置中配置 `WORKBENCH_SETUP_TOKEN`，首次页面填写相同初始化码。已有管理员不能被再次初始化覆盖。
- 部署后设置 `WORKBENCH_PUBLIC_ORIGIN=https://实际应用域名`，用于来源检查与 Secure Cookie。只能设置完整来源，不含路径。使用提供的代理时不要移除 `X-Workbench-Proxy` 标记。其他代理必须剥离客户端同名头并由代理重新写入。
- 登录会话保存在内存，12 小时到期，重启后需要重新登录；使用 HttpOnly、SameSite=Strict Cookie，应用应以独立页面打开。当前实现适用于单个 Python 进程；多实例需要共享认证、配置及任务存储。
- 当前项目仍是本机启动的应用；添加管理入口不等于已部署公网，也不代表现有全部业务接口已完成团队权限改造。身份限制覆盖生图、模型配置和验证接口；启用共享文案 Key 后，生成、修改与文案连接验证也要求团队登录。

官方协议参考：[千问图像生成与编辑](https://help.aliyun.com/zh/model-studio/qwen-image-generation-and-editing-api-reference)、[获取 API Key](https://help.aliyun.com/zh/model-studio/get-api-key)。
