## 作品概述

作品名称：华为 PC 营销软文智能体。

目标：帮助门店导购和内容运营，根据产品、人群、场景与平台，从指定 ima 共享知识库获取事实及图片，生成有依据的图文内容，并给出核验结果。

当前完成情况：本地工作台、规则版场景与平台演示、结构检查、手动编辑与导出，以及 ima 共享库连接、目录与条目检索、原文和图片读取、选中资料批量调用已实现；大模型生成和完整语义核验待开发。说明书正式提交前仍需加入真实完整生成运行结果。
