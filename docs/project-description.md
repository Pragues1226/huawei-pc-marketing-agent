# 华为 PC 营销软文智能体作品说明

## 作品概述

本作品面向门店导购和内容运营：输入明确的华为 PC 型号、目标人群、使用场景、发布平台与内容目标，系统从赛题指定的 ima 共享知识库读取产品原文和图片，组织小红书、公众号或门店朋友圈图文，并展示事实来源和核验结果。目标是让场景表达有依据，也让无法确认的产品声明停在交付之前。

当前仓库包含可运行的本地浏览器工作台、自研 Agent 流程、ima 只读接入层、提示词和自动测试。正式参赛账号与模型凭证由运行者在本机配置，仓库不包含共享库原文、图片副本或密钥。

## 操作流程

1. 在任务表单填写具体型号、受众、场景、平台、购买阶段和内容目标。型号不清或关键字段缺失时，工作台提示补充。
2. 搜索或浏览指定 ima 共享库，人工选择当前型号的产品原文与图片。搜索为空时可以进入目录查找；每次最多选择八份资料。
3. 点击“生成并核验图文”。Agent 从原文提取带逐字引句的事实，制定场景与平台策略，生成标题、正文、行动引导、标签及配图位置。
4. 程序检查原文引句是否存在、事实和图片是否属于当前型号、引用与图片数量是否满足平台要求，再用独立模型调用检查声明、语气和营销表达。
5. 通过后展示场景策略、知识库依据、图文和核验结果。编辑标题、正文或行动引导后重新核验；未通过时停止复制和导出。

演示预览使用虚构占位内容并明确标注，不能作为真实产品运行结果。真实模式中的 `ready` 代表自动核验通过，发布前仍需人工阅读原文、查看图片画面和复核营销表达。

## 自研 Agent 与 ima 的分工

ima 提供指定共享库的资料定位、原文、图片和来源信息。团队自研部分负责输入检查、场景分析、三平台策略、事实提取、图文生成、结构校验、语义核验和异常阻断。原文引句与来源 ID 随事实保存，图片只能引用本次检索得到的本机资源；资料中的文字作为待验证数据处理，不会覆盖 Agent 的系统要求。

三平台的输出规则分别为：小红书 3–6 张图、短段落和话题标签；公众号 2–4 张图、导语和分节正文；门店朋友圈 1–3 张图、短文案和单个核心卖点。切换场景时，模型重新选择切入点、事实顺序和配图理由。

## 系统提示词与核验

系统提示词见 [prompts/system.md](../prompts/system.md)。它要求模型只从本次指定 ima 原文提取产品参数和卖点，保留适用条件，不能把其他型号、历史价格或示例文章当作当前型号事实；不能伪造个人体验、优惠、竞品结论或图片链接。事实提取、内容生成和独立核验分别调用模型。程序还会对引句、引用 ID、来源状态、图片数、平台结构和高风险词作确定性检查。

证据不足、检索警告、图片不足、错误型号、模型未完成核验、事实无依据或宣传风险出现时，系统返回阻断原因，成稿复制与导出不可用。自动核验是辅助审查，不能替代队员对知识库原文和图片画面的终审。

## 运行与验证

在 Python 3.10 或更新版本的环境中安装 `requirements.txt`，将 `.env.example` 复制为本机 `.env`，配置 ima 官方脚本、参赛账号凭证和兼容 OpenAI Chat Completions 的模型接口，然后运行 `python -m app`。浏览器打开 `http://127.0.0.1:8765`。详细字段与步骤见 [README](../README.md)、[ima 接入说明](ima-setup.md)和[工作台说明](workbench.md)。工作台只监听本机回环地址。

仓库自动测试共 73 项，覆盖 ima 接口边界、真实资料读取、来源编号、引句存在性、图片型号筛选、三平台规则、生成与修改后复核接口。前端脚本语法和本地页面也已检查。这些测试使用模拟外部响应，不能充当参赛账号的真实运行证明。

初赛说明书需至少附一组可辨认的真实运行结果。当前电脑尚未配置 ima 官方脚本、共享库凭证和模型接口，因此本仓库截至 2026 年 10 月 18 日没有可核验的完整真实生成结果。本节需在参赛账号运行后补上：任务输入、场景策略、逐字引句及来源、最终图文、图片来源与位置、核验状态和页面截图。推荐先运行 [验收任务 T01](acceptance.md)：明确型号、大学新生、开学购机、小红书。

按赛题要求，初赛还需提供评审期可访问的 GitHub、魔搭页面与作品说明书链接。当前 GitHub 开发分支和草稿 PR 可供团队审阅；公开评审访问、魔搭展示页和真实运行结果仍须在最终提交前完成。复赛另需至少三组覆盖两类场景与两个平台的优秀结果，以及连续真实运行录屏。

## 已知限制

- 本地工作台没有公网部署地址；魔搭展示页可先展示项目与运行方式，但不能代替可访问的真实应用演示。
- 图片型号先依据指定库中的标题和目录筛选，实际画面仍需人工核对。
- 模型语义核验可能遗漏隐含宣称；发布前需人工终审，价格、优惠和时效信息尤其需要再次确认。
- 未配置或失效的 ima、模型凭证会阻止真实生成；知识库权限、接口额度及资料完整度由参赛运行环境决定。
