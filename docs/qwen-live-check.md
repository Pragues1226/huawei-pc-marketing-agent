## 发现与修复

1. 默认通用域名的 OpenAI Images 路径返回非 JSON 404；同域名原生多模态路径可用。补充原生请求与响应结构，工作空间域名继续支持原 Images 结构；不设置自动付费回退。
2. 百炼返回的 OSS 加速域名不在原有结果下载白名单。补充精确的官方域名规则，并添加相似域名拒绝测试；仍不接受任意远程 URL。
3. 浏览器验收脚本使用混合斜杠的下载目录时，Edge 下载完成前取消保存。对照普通文本与相同 PNG 后，改用 Windows 原生路径，实际网站下载成功；没有为此更改网站逻辑或浏览器安全策略。

## 尚未覆盖与限制

真实生成只覆盖方图，不扩展为所有模型、地域和比例均已实测。配置及权限测试同时包含模拟数据，不能把模拟输出当作真实模型证据。当前只实现独立场景生图与下载；图生图、自动产品合成、自动插入营销稿、长期图片图库及完整广告生成验收仍待完成。预览图片在内存中保留约 1 小时，重启后清除，已下载文件不受影响。
