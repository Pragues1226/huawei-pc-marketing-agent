# 官网产品资料与 v7 创作指导

本轮在用户明确授权下增加华为消费者官网产品来源，并从用户指定的 v7 目录读取写作指导。官网、ima、本地压缩包分别标注来源，不把官网或本地内容说成 ima 实时检索。

## 使用

1. 双击项目根目录的 `start-workbench.cmd`，打开本机工作台。
2. 点击“开始创作”进入景观界面；点击“创作任务”，面板在屏幕中心展开，其他功能向后缩小、淡化。关闭按钮或 Esc 恢复卡片；卡片可横向滚动。
3. 选择“真实图文创作”，资料来源选择“华为官网”。填写完整型号、平台、人群、场景和目标。型号列表当前覆盖 v7 的十个重点 PC 产品，区分鸿蒙版、Windows 版和年份；不明确的型号不会自动猜测。
4. 点击“读取官网介绍与图片”可单独查看实际官网资料，无需模型。介绍保持官网措辞；展开“官网原文”可查看说明、脚注与条件。展示来源链接、读取时间与对应图片，可点击缩略图切换。
5. 点击创作按钮时，系统自动读取官网资料，再把该型号事实、真实图片和按任务选取的 v7 指导交给模型。管理员可在网站连接设置中配置团队共用模型，见[文案与图片核验模型](shared-text-model.md)。新下载的源码不包含凭证，未配置时会提示配置缺失。

## v7 指导

本机 `.env` 的 `GUIDANCE_ROOT` 指向用户指定的“华为PC全板块深度知识库_v7”文件夹，直接只读使用，不复制整个知识库，不把全文放进公开仓库。

每次任务读取治理/引用规则、相应平台模板，以及匹配的型号角色话术与客户场景。学生任务优先学生沟通卡。指导内容仅用于结构、语气、场景与表达；其中参数、价格与虚构案例不能覆盖本次产品事实。模型修改稿时继续沿用该次指导和原始证据。

界面显示实际读取的指导文档标题；完整私有内容仅在正式模型生成时作为所授权的上下文使用。

## 来源与限制

- 官网目录由 v7 的十个重点型号来源清单建立，路径固定在服务端；页面与图片实际读取自 `consumer.huawei.com`，仅允许该域名的 HTTPS，跳转也重新检查。官网网络异常不会换成演示图。
- 官网图采用同源内存图片引用，检查真实图片签名并按内容去重；不让浏览器接收官网会话或任意代理地址。缓存约一小时；服务重启或缓存淘汰后需重新读取。
- 原文仅整理 HTML 空白，保留说明条件；超过限额停止读取，不截去条件继续生成。官网介绍的展示保持原文，最终广告重新组织，事实必须能追溯到片段引用。
- 官网图片与内容的权利仍归原权利人；系统保留来源，发布用途应由使用者确认。官网路径或页面结构变化时可能需要维护读取规则。
- 模型未配置时可以读取官网资料和体验演示排版，不能声称完成真实广告生成。自动核验即使通过也需要发布前人工复核。

## 验证

97 项业务测试通过，覆盖现有生成/检索流程、官网型号与来源限制、过期引用、指导匹配及生成/修改上下文。实际连接官网读取了鸿蒙版 MateBook 14 的原文和六张图片，并确认图片由本地接口正常返回。

早期浏览器检查覆盖 1700×920 和 390×844：中心面板、卡片退缩与恢复、演示生成、各功能、官网图片切换、学生 v7 指导、Esc、减少动态效果、无页面横向溢出。后续已完成一组官网真实任务的生成、修稿和自动核验通过，最新记录与限制见[真实图片写作与逐图核验](image-grounding.md)；多场景完整验收仍待完成。
