⌘

完成四步再开始真实创作

  1. 用同一账号加入共享库

    扫描赛题手册第 7 页二维码，确认共享库出现在 ima 中。

  2. 配置 ima 访问

    在官方接口页获取 Client ID 与 API Key；项目已连接本机 ima 技能脚本。凭证保存在仓库根目录的 .env，不要发到聊天或提交到 Git。

    打开 ima 官方接口页 ↗
  3. 配置图文模型

    DeepSeek V4.1 Flash 的官方 API 配置为 LLM_BASE_URL=https://api.deepseek.com、LLM_MODEL=deepseek-flash；本机已启用 JSON 输出模式。API Key 只在本机 .env 填写。

  4. 重启并检查连接

    重启工作台，刷新本页状态，再测试模型和共享库。连通后切到“真实资料创作”。
