# 应用模块

已有浏览器工作台：任务输入、场景预设、三平台演示、内容策略、来源状态、核验结果、修改、复制与 Markdown 导出、浏览器历史，以及真实 ima 连接检查和条目检索。

运行 python -m app，打开 http://127.0.0.1:8765 。实现为 Python 标准库本地服务与静态页面，复用 contracts/ 的任务和结果结构。

演示使用占位资料与通用构图，不调用模型；真实模式已经可以浏览目录、读取产品资料原文与实际图片、选择并批量取回资料供后续调用。大模型生成和产品语义核验仍待联调。详见 ../docs/workbench.md 和 ../docs/knowledge-retrieval.md。
